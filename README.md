# Lumière Smart Menu

Premium landing page for smart restaurant menu tablets.

## Run locally

Open `index.html` in a browser, or serve the project with any static server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000

## Files

- `index.html` — landing page structure
- `styles.css` — premium restaurant design and responsive layout
- `script.js` — small interaction for tab switching

## Project goal

This landing page is designed for restaurants and cafes that want to sell modern smart-menu tablet solutions, increase average check, improve order speed, and deliver a premium guest experience.
